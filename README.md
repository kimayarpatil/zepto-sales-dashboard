# Zepto Sales & Inventory Dashboard

## Overview
This project presents an interactive **Power BI dashboard** created to analyze product sales, revenue, and inventory data from Zepto.
The dashboard helps visualize key business insights such as product demand, category performance, and stock availability.

## Problem Statement
Quick commerce platforms manage thousands of products, making it difficult to manually analyze sales trends and inventory levels.
This project aims to simplify data analysis using an interactive dashboard.

## Solution
A Power BI dashboard was developed to visualize important metrics including:
* Total Revenue
* Total Orders
* Product Categories
* Stock Availability
* Out-of-Stock Products
Interactive slicers allow users to filter and explore the data easily.

## Tools Used
* Microsoft Power BI
* Power Query
* DAX
* Excel Dataset

## Key Insights
* Total revenue generated: **12.23B**
* Total products analyzed: **3732**
* High demand categories include **Cooking Essentials and Munchies**
* Some categories experience **frequent stock shortages**
